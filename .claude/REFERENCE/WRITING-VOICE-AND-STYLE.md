## How to read this file

- **Script-writer agent:** read everything except PART 6 (ARTICLE WRITING) and PART 7 (article-only toolkit).
- **Article-writer agent:** read PART 1 (CORE VOICE) + PART 2 (EVIDENCE AS NARRATIVE) + PART 6 (ARTICLE WRITING) + PART 7 (toolkit).
- **Pointer rule:** where a single rule legitimately differs between script and article, the difference is stated inline as `Script:` / `Article:` — never punted to a separate file.
