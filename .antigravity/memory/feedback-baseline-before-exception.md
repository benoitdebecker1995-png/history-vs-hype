# Baseline-Before-Exception

**Rule:** For any "but actually" / "loophole" / "exception" / "rule X applies" / "however" / "in fact" beat in a script, the baseline being subverted MUST be established before the beat lands. Pick a lane:

- **Path A (VO scaffold):** name the default interpretation, anchor it to textual evidence in the document, attribute the consensus reading.
- **Path B (Visual scaffold):** `[ON SCREEN]` cue shows the actual document/law text/evidence; VO references it deictically.

If neither path is specified, the beat fails the audit and the thesis erodes.

**Why:** Inquisition #54 (2026-05-09) had a locked thesis of *"Torquemada wrote the rules. The loophole was in the same paragraph."* But the script never articulated the rule the loophole loopholes. §3 covered procedural rules (personnel, warnings, ratification) but never the "one torture session only" baseline that §XV's final sentence is an exception to. So when §4 declared "rule and escape hatch, written together," the listener had nothing to map "escape" against. User patched live during recording: *"This phrase is cited by historians to conclude that torture could only occur once. Why else would you use the word 'repeat' as an exception?"* — Path A scaffold doing the missing inferential work.

Same failure recurred at §5 (silence=innocence asserted with no rule-establishment) and §2 (CIA cold/hot blood frame pivoted off with no visual anchor). User's patch path for §5+§2 is visual (Path B) — show the law text, show the CIA chaos reports — confirming the two-lane structure of the rule.

**How to apply:**
- During script writing: tag every pivot beat. For each, commit to Path A (write the scaffold into VO) or Path B (write the `[ON SCREEN]` cue). If neither fits, ask whether the beat is actually load-bearing.
- During structure-checker pass: Constraint BC enforces. Format C = BLOCK on missing pair; Format A/B = WARNING.
- Connection to Rule 36 Thesis Discipline: if locked thesis contains "loophole/exception/but/however/actually" — the antecedent of that pivot must appear before the pivot does. Walk-Away Test fails otherwise.

**Format-specific severity** (per 2026-05-09 retroactive audit, n=33 beats across Tripoli #51 + Manhattan #45 + Hijab #52, 33/33 PASS):
- **Format C (forensic close-read):** MANDATE. Format C scripts are uniquely vulnerable.
- **Format A/B + document-first/myth-first:** default-on, relaxable. These formats typically pass naturally because format itself forces primary-evidence visibility.
