# YouTube-native replacement assets

These files replace the presentation-style cards in the parent folder. Use the original archive page as the image; use typography only to identify provenance or direct the viewer's eye.

- `*-wide.png`: establish the complete page for 1–2 seconds.
- `*-detail.png`: match-cut or push into the relevant clause.
- `*-fullscreen.png`: full-bleed map treatment.
- `overlay-*.png`: transparent Resolve overlays, not title slides.
- `motion-*.mp4`: ready-to-use silent 1080p source sequences.

The parent-folder cards `01`–`18` are retained only as reference and should not define the final video's visual language.
