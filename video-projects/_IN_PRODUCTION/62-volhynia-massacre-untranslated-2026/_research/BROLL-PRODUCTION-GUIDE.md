## 🛠 PRIORITY 1: THE TWO MISSING MAPS (2–3 hours total)

### MAP 1: The Volhynia / Eastern-Galicia Orientation Map (Foundational Context)

**What it shows:** The borderland geography — where Volhynia is, Polish-Ukrainian border shifts, the region in relation to modern Poland/Ukraine, key cities.

**Why it matters:** Viewers need to *see* Volhynia's location before the massacre makes sense. ACT 1 cold open needs a reference geography.

**Free Tool:** MapChart.net OR Google My Maps (Google My Maps = faster for simple borders)

#### Option A: Google My Maps (FASTEST — recommended, ~20 min)

**Step-by-step:**

1. Go to **google.com/maps** → click menu (hamburger icon) → **"Your places"** → **"Maps"** → **"Create map"**

2. **Name the map:** "Volhynia_EasternGalicia_1943"

3. **Add base map layer:**
   - Zoom to Eastern Europe (Poland/Ukraine border region)
   - Center on Lviv (Lwów), which is inside the Volhynia/Eastern-Galicia region
   
4. **Draw boundaries (using "Draw a line" tool):**
   - Click **Drawing tools** (pencil icon) → **"Draw a line"** → select **"Dashed line"** (to indicate historical boundary, not modern)
   - Draw the approximate pre-1943 Polish-Ukrainian ethnic boundary in Volhynia
   - Repeat for Eastern Galicia boundary
   - Use **color-coding:** 
     - Polish-controlled areas: outline in RED
     - Ukrainian-concentrated areas: outline in BLUE
     - Volhynia region itself: highlight center region in YELLOW

5. **Add key markers (pushpins):**
   - **Lviv** (Lwów) — major city, reference point
   - **Lutsk** — center of Volhynia
   - **Cholim/Chełm** — Polish town in the region
   - **Rivne** (modern Ukrainian city)
   
6. **Add text labels:**
   - Click "Add text label" → type region names:
     - "VOLHYNIA"
     - "EASTERN GALICIA"
     - "Pre-1943 Polish-Ukrainian Border"

7. **Export as PNG:**
   - Screenshot the final map using **Windows Snipping Tool** (Win + Shift + S)
   - Crop to the region only
   - Save as: `volhynia-orientation-map.png` in `_research/exhibits/maps/`

**Quality check:** The map should show Volhynia as a clear northern region, Eastern Galicia below it, with modern city names labeled for reference. Viewers should instantly understand "this is the borderland between Poland and Ukraine."

**Fallback (if Google My Maps frustrates):** Use MapChart.net → select "Europe" template → manually color Poland/Ukraine → download PNG → open in PowerPoint to add labels + lines.

### MAP 2: The 11 July 1943 Coordinated Strike (The Massacre Scale)

**What it shows:** ~100 villages hit in ONE MORNING on July 11, 1943. This is THE KEY VISUAL to prove the massacre was coordinated, not "spontaneous peasant anger."

**Why it matters:** Script says *"On the morning of July 11th, 1943, the UPA hit around a hundred Polish villages at once."* This visual PROVES "at once" — the simultaneity is the smoking gun.

**Free Tool:** MapChart.net (specifically its "Europe" regional maps feature)

**Step-by-step:**

1. Go to **mapchart.net**

2. **Select the map type:**
   - Choose **"Europe"** → then **"Ukraine + Poland"** (or select the region that includes Volhynia)
   - Alternative: Start with "World" and zoom to the Volhynia region

3. **Create a base map:**
   - This will be your Volhynia-region map for 1943
   - MapChart will let you select and color regions (you'll use villages/localities instead)
   - **Switch to "Custom regions" or "Regions" mode** if available to zoom to a specific area

4. **Mark the 100 villages:**
   - Unfortunately, MapChart doesn't have a "village" granularity — it works at administrative levels
   - **WORKAROUND:** Use color-coded dots or markers for the approximate locations
   - **Alternative approach (BETTER):** 
     - Export the base map from MapChart as PNG
     - Open in **PowerPoint**
     - Use **Insert → Icons → search "circle"** to add red dots at ~100 approximate village locations
     - Add a legend: "Red dots = ~100 Polish villages attacked July 11, 1943"

5. **If using MapChart directly:**
   - Color the administrative regions (districts/rayons) where the massacres occurred in RED
   - Lighter shade = edges of the killing zone
   - Darker red = epicenter (highest concentration)
   - Add a title overlay: "July 11, 1943 Coordinated Strike — ~100 villages, one morning"

6. **Export and refine:**
   - Download MapChart as PNG
   - **Open in PowerPoint** to add:
     - A red legend key
     - Arrows showing direction of attack (if you have that data — optional)
     - City labels (Lutsk, Volodymyr, Rovno for reference)
   - Export the PowerPoint slide as PNG

7. **File naming:**
   - Save as: `july-11-1943-massacre-villages-coordinated.png` in `_research/exhibits/maps/`

**Quality check:** The map should visually scream "look at how many places were hit on the same day." Viewers should see geographic spread (not a single village) and simultaneity (everything red at once).

**Data source note:** McBride p.640 says "over 100 localities" and ~4,000 killed. You don't need a perfect village list — approximate the geography based on the Volhynia region's administrative layout. The point is the visual proof of coordination.

**Optional enhancement (if time):** Create TWO versions:
- Version A: Just the dots/coloring (simple)
- Version B: Add arrows showing the geographic spread + time zones (if UPA was coordinated across time zones, add that as a footnote)

3. Layer it on top as a text/graphic overlay
4. Alternate between the document + the dossier card + the next asset

### How to Use This Template

**For each on-screen document beat:**

1. **Open the HTML file** in any text editor (VS Code, Notepad++)

2. **Replace placeholders** (in CAPS):
   - `[TITLE]` → e.g., "Act of Restoration of the Ukrainian State"
   - `[DATE]` → "30 June 1941"
   - `[QUOTED TEXT]` → the exact quote from the script
   - `[ORIGINAL LANGUAGE TEXT]` → if the document is Ukrainian/Polish, show the original
   - `[AUTHOR/INSTITUTION]` → McBride, Himka, etc.
   - `[CAVEAT TEXT]` → if needed (duress, translation, etc.)

3. **Save as a new filename:**
   - `dossier-act-1941.html`
   - `dossier-order11.html`
   - `dossier-stelmashchuk-testimony.html`
   - etc.

4. **Render to PNG:**
   - **Option A (easiest):** Open the HTML in a web browser (Chrome/Firefox) → right-click → "Print to PDF" → Open in an image editor, crop to 1920×1080, export as PNG
   - **Option B (faster for video):** Use **Playwright** (free Node.js library) to screenshot the HTML directly:
     ```bash
     npx playwright install
     # Then use the script below
     ```

5. **Use in DaVinci:**
   - Import the PNG as a media clip
   - Layer it over the document image
   - Add a transition (fade in/out) at the start/end
   - Keep on screen for ~4–6 seconds (time for reading)

## §8: TROUBLESHOOTING

### "My map doesn't show exactly 100 villages"
**Solution:** MapChart/Google My Maps don't have village-level granularity. Approximate the footprint based on districts/towns. The point is the VISUAL PROOF of simultaneity, not perfect accuracy. Viewers understand "the region was hit at once," not "exactly 87 villages at 03:15 UTC."

### "The dossier card text is too small when rendered as PNG"
**Solution:** Increase the font sizes in the HTML (change `font-size: 18px` to `24px` for the quote, etc.). Test at 1080p in your editor before finalizing.

### "Order No. 11 — how do I show the "liquidate" clause without cropping?"
**Solution:** 
- In DaVinci, import the Order No. 11 scan
- Add a **red box / highlight** around point 2, but make sure the FULL OBJECT is visible (the "German/Bolshevik" enemy text)
- Narrate: "It's about defending villages from German raids" — the VO anchors the meaning; the visual confirms it's not a massacre order
- Optionally add a text card: "Point 2: liquidate [German/Bolshevik enemy]" (translation alongside)

### "I don't have time to do both maps"
**Priority order:**
1. **July 11 map is CRITICAL** — it's the smoking gun for "coordinated." Without it, the crux beats fall flat.
2. **Orientation map is high-value** — it helps viewers understand geography, but you can survive without it (the VO establishes Volhynia is a borderland).

If you must skip one, skip the orientation map and use a 30-second text explanation ("Volhynia is a borderland region between Poland and Ukraine in the northwest") during ACT 1.

### "Which dossier cards are truly essential?"
**Ranked by load-bearing:**
1. **Stelmashchuk testimony** — this is the crux; the duress caveat MUST be clear
2. **Order No. 11** — this is the forensic contrast; the "liquidate" clause must be readable
3. **Act 1941** — this is the twist; the Hitler collaboration must be legible
4. **Lebed directive** — nice-to-have; if time is short, you can card it as a scholar quote (McBride p.631 instead of a standalone dossier)

If you only have 1 hour for dossier cards, prioritize cards 1 & 2.
