## Executive Summary

The corpus is text. None of the 13 papers is a video. But several use moves that translate cleanly to video: **stageable scenes, sentence rhythms that match cut patterns, paragraph handoffs that mirror retention beats, recurring anchors that hold a long runtime, turn techniques that map to the 15-25% pivot.**

Script-writer-v2 bumps **v14.5 → v14.6**. Eight new rules / refinements, two new format templates, and a corpus-exemplars reference shared with article-writer.

**Top 5 highest-leverage changes for video:**

1. **NEW Rule 38: Stageable Scene Discipline (S11)** — every evidence beat must be buildable as a STAGEABLE SCENE (single iconic visual + embedded dialogue + analytical inference left to viewer), not as quoted documentary cutaway.
2. **NEW Rule 39: Recurring Anchor (S14)** — pick ONE named thing using the SAME WORDING in cold open + every act + close. The 10-min runtime needs something to hold onto.
3. **NEW Rule 40: Turn Pattern Selection (S15)** — for the 15-25% turn, pick ONE of four landing techniques (default = paradox-questions for video). Always concede first.
4. **NEW Rule 41: Concede-and-Pivot Architecture (S10)** — the opening-sentence concede-and-pivot must mirror the macro structure. Unity of rhetoric and architecture.
5. **NEW Format Template: THE GINZBURG FORMAT (S5)** — three-case braid + shared-origin reveal. Works for "Three [X] That Failed for the Same Reason" comparative HOW-mechanism content.

## STRONG SIGNALS (high-leverage video upgrades)

### Rule 38 — Stageable Scene Discipline (NEW)
**Validated across:** Wolfe (Cherokee dinner-table-to-burning-homes), Davis (Montauban priest-on-donkey), Trouillot (classroom interruption), Crane (1892 banner over Stars and Stripes), Mamdani (Tecumseh refusing the chair) — S11

```
+ Rule 38 (HARD): Every evidence beat in a script must be buildable as a
+   STAGEABLE SCENE, not as a quoted documentary cutaway from talking head.
+   Three required properties (all three, every scene):
+     (a) ONE ICONIC VISUAL element anchors the scene — a single image you
+         could thumbnail (bayonets in doorway / priest on donkey / banner
+         over flag / chair refused).
+     (b) PRIMARY-SOURCE DIALOGUE EMBEDDED INSIDE the scene, not cut to as
+         separate testimony. Tecumseh's reply IS the scene; the Cobbett
+         banner-text IS the scene.
+     (c) ANALYTICAL CLAIM LEFT FOR VIEWER TO INFER. Don't VO "this illustrates
+         the logic of elimination" — show bayonets in the doorway and trust
+         the audience.
+   Test: could a director storyboard this in 3-5 shots from the script
+   alone? If yes = scene (high retention, high B-roll efficiency). If no =
+   quoted evidence (probably less retentive, requires invented visuals).
+   Anti-pattern: VO summarizes a primary source while talking head fills
+   the screen. Channel already has "primary sources on screen" rule —
+   this rule goes deeper: build the script's key moments as scenes.
+
+ Direct project hit: Crane's 1892 Central Music Hall banner-over-Stars-and-
+   Stripes is a B-roll opportunity for project 51. Single hero shot —
+   banner with Article 11 text hung over the flag — carries the entire
+   "secularists made this treaty their flag in the 1890s" beat.
```

### Rule 39 — Recurring Anchor Discipline (NEW)
**Validated across:** Trouillot, Snyder, Crane, Wolfe, Cronon (5 papers — S14)

```
+ Rule 39 (HARD — pre-publish gate): Every script must have ONE named
+   recurring anchor that appears in cold open + every act + close using the
+   SAME WORDING.
+   Three valid types:
+     (a) COINED-TERM (e.g., "the unthinkable", "logic of elimination") —
+         coin or seize a term that becomes the script's analytical anchor.
+     (b) PROPER-NOUN-AS-SYMBOL (e.g., "Auschwitz" used as the named foil) —
+         a famous thing the script is dismantling. Each return reinforces
+         what it OBSCURES.
+     (c) SPECIFIC-EVIDENCE (e.g., "Article 11", "the Pajak treaty") — actual
+         document/event as spine. Use the EXACT same name every time. Never
+         paraphrase ("the secularism clause" → say "Article 11").
+   Pre-publish check: read the script and identify the one named thing that
+   appears in cold open + every act + close. If absent, add one or accept
+   that the script will feel jumpier than necessary.
+   Pairs with Rule 41: anchor and macro structure should do the same work.
+   Snyder's "Auschwitz" recurs because the structure is dismantle-Auschwitz /
+   rebuild-bloodlands. Unified.
```

### Rule 40 — Turn Pattern Selection (NEW)
**Validated across:** Crane, Trouillot, Davis, Wolfe (4 papers — S15)

```
+ Rule 40 (STRUCTURAL): The 15-25% turn must use ONE of four landing
+   techniques. All four share concession FIRST, claim SECOND.
+     (a) LENS-SHIFTING ROADMAP — "It's through this lens, rather than
+         the [conventional reading], that we can best understand..."
+         Best for: myth-busting that needs a trajectory map after the turn.
+     (b) PARADOX-FRAMING QUESTIONS (RECOMMENDED VIDEO DEFAULT) — 2-3
+         escalating questions that pivot from setup to thesis.
+         Best for: high-level conceptual challenges. Creates open-loop
+         retention beat — viewer wants the answer.
+         Example structure: "If X, how can Y? In other words, can Z?
+         How does one even Z?"
+     (c) HISTORIOGRAPHIC "BUT" PIVOT — concede prior reading, ask the
+         question that opens new space.
+         Best for: challenging a specific scholarly position by name.
+     (d) "I CONTEND" THESIS DECLARATION — naked commitment after concession.
+         Best for: sharp claims that can land alone (rare in video — usually
+         needs prep).
+   Anti-pattern: drift from setup into body without a visible turn. Channel
+   data: avoid 25-35% turn placement (2.1x dead zone); 15-25% wins (3.2x).
```

### Rule 41 — Concede-and-Pivot Architecture (NEW)
**Validated across:** Snyder explicitly + every concede-and-pivot exemplar — S10

```
+ Rule 41 (STRUCTURAL): If the cold open / hook is a concede-and-pivot at
+   sentence level, the macro structure must mirror it at architecture level.
+   Unity of rhetoric and architecture.
+   Sentence-level: "X is in fact only Y."
+   Article-level (mirrored): dismantle X, rebuild Y. The whole script is
+   the same move at larger scale.
+   When scripts feel jumpy, check: does the body do what the hook promised?
+   If no, fix the body or fix the hook.
+   Snyder is the cleanest example: opening sentence ("Auschwitz... is in
+   fact only the beginning of knowledge") = whole article shape (dismantle
+   the conventional, rebuild around the bloodlands).
```

## NEW FORMAT TEMPLATES

### THE GINZBURG FORMAT — Three-Case Braid + Shared-Origin Reveal
**Validated source:** Ginzburg "Clues" — S5

```
+ Format: THE GINZBURG FORMAT (3-case comparative HOW-mechanism)
+   Structure (8-10 min video):
+     0:00-0:30 — Cold open: tease the puzzle. "These three things look
+                 unrelated. Watch what happens when you put them next to
+                 each other."
+     0:30-2:30 — Case A: present the case in full, but withhold the
+                 mechanism analysis.
+     2:30-4:30 — Case B: same.
+     4:30-6:30 — Case C: same.
+     6:30-7:30 — TURN (S15 paradox-question default): "What do these three
+                 cases have in common that nobody talks about? Watch this."
+     7:30-9:00 — REVEAL: name the shared mechanism explicitly.
+     9:00-10:00 — Origin reveal: trace the mechanism to its deeper cause/
+                 source. Close.
+   Working title patterns:
+     - "Three Border Disputes That Failed for the Same Reason"
+     - "Three Treaties Whose Identical Flaw Nobody Noticed"
+     - "Three Lost Cities Built From the Same Colonial Lie"
+   Why it works for the channel: HOW>WHY axis (mechanism > narrative). The
+   reveal at the turn is the payoff that makes comparative content worth
+   more than its parts.
+   Validated source: Ginzburg's "Clues" links Morelli (art), Holmes
+   (detection), Freud (psychoanalysis) via shared medical-semiotics origin.
```

### THE CRONON FORMAT — Variant B of Same-Evidence-Multiple-Readings
**Validated source:** Cronon "A Place for Stories" — S3 Variant B

```
+ Format: THE CRONON FORMAT (synchronic interpretive contest)
+   Premise: same evidence, two contemporary historians, opposite conclusions.
+   The video teaches the audience that historiography itself is a
+   battleground.
+   Structure (8-10 min):
+     0:00-1:00 — Cold open: the puzzle. "Two historians read the same
+                 evidence and wrote opposite books. Both are right.
+                 Both are wrong. Here's what that means."
+     1:00-3:00 — Reading A: present scholar A's case, on its own terms.
+     3:00-5:00 — Reading B: present scholar B's case, on its own terms.
+     5:00-6:00 — TURN: "How is this possible? Both are reading the
+                 same documents."
+     6:00-9:00 — Mechanism: how do worldview / methodology / political
+                 commitment shape what each historian SAW in the evidence.
+     9:00-10:00 — Implication: what this teaches us about reading any
+                 historical claim. Close.
+   Working titles:
+     - "Two Historians Read the 1819 [X] Treaty. They Couldn't Agree
+        on a Single Thing."
+     - "Why Worster and Bonnifield Wrote Opposite Books About the Same Drought."
+   Why it works for the channel: meta-level HOW>WHY — the mechanism is
+   historiographic method, not historical event. Differentiated from
+   competitor channels that stay at event-level.
```

## STRUCTURAL UPGRADES

### Rule 42 — Section Transition Mechanism (mirrors article-writer Rule 24)
**Validated across:** Cronon, Trouillot, Wolfe (3 papers — S13)

```
+ Rule 42 (STRUCTURAL): Every section break in a script must use one of
+   three handoff mechanisms.
+     (a) RAISED-QUESTION-THEN-ANSWERED (Cronon mode): VO ends prior section
+         with a question on screen, transitions to "the answer". Open
+         loop / close loop retention beat.
+     (b) ECHO WORD (Trouillot mode): VO ends on key term (also displayed
+         as chyron), next beat picks up the same word. Word-level
+         continuity = audio-visual continuity at the cut.
+     (c) THEMATIC INTERROGATION (Wolfe mode): primary source on screen →
+         analytical question pulled from the source's metaphor → analytical
+         answer. Built-in retention move.
+   Anti-pattern: "Now let's turn to..." default. The handoff IS the
+   engagement.
```

### Rule 43 — Sentence-Rhythm-to-Cut-Pattern Mapping (toolkit)
**Validated across:** Snyder, Trouillot, Davis, Darnton — S12

```
+ Rule 43 (TOOLKIT): When a script beat needs energy, name the rhythm
+   the script is invoking and pre-bake the cut pattern into the VO.
+
+   (a) CHAIN REPETITION (Snyder mode): clause-end = clause-start.
+       Inescapable causal closure.
+       VO instruction: hold a beat of silence at the comma so listener
+       feels the closure before the meaning lands.
+       Cut pattern: hold one image for the full sentence; the rhythm IS
+       the visual.
+
+   (b) ACCUMULATING PARALLELS (Trouillot mode): "from X to Y, from X to
+       Y, from X to Y" compressing time.
+       Cut pattern: each clause = date stamp + 1 image + 1 second. Whole
+       arc in 13 seconds.
+
+   (c) STACCATO-TO-CASCADE (Davis mode): short blunt anchor → release into
+       long cascade whose clauses mimic action.
+       Cut pattern: hard-cut establishing shot with short VO → release
+       into longer montage as VO cascades. Short sentence is the BEAT
+       before the wave.
+
+   (d) LIST PROPULSION (Darnton mode): rapid action verbs in a string +
+       unconjoined noun-list closer.
+       Cut pattern: each verb = one shot. Noun-list = 4 snap-cuts on closer.
+
+   Don't write "vary sentence length" — pick the rhythm that matches the
+   action. Sentence rhythm and visual editing are the same thing at
+   different scales.
```

### Rule 44 — Decode-Not-Defer for VO (S6, S7)
**Validated across:** Hobsbawm (word-zoom), Darnton (questioning re-entry), plus all the article-writer Rule 13b validators

```
+ Rule 44 (STRUCTURAL — pairs with on-screen primary source): When a primary
+   source quote appears on screen, the VO that follows must DECODE the
+   quote, not summarize it. Pick one of three video-tested sub-patterns:
+
+   (a) WORD-ZOOM DECODE (Hobsbawm mode): VO highlights ONE word from the
+       on-screen source. "Notice the word [X] — that one word is doing
+       all the work." Visually pair with an on-screen word highlight
+       (color shift, underline animation).
+
+   (b) QUESTIONING RE-ENTRY (Darnton mode): VO asks the interpretive
+       question the source raises. "What is going on here?" creates
+       retention beat — viewer wants the answer. Use when the source
+       is genuinely puzzling AND you're about to overturn a standard reading.
+
+   (c) POLITICAL-INTEREST DECODE: VO names whose interest the speaker is
+       serving. "[Speaker] singles out [X] because..." — turns surface
+       quote into political move.
+
+   Anti-pattern: VO paraphrases what the source said. Audience can read.
+   The VO's job is to do something the source can't do for itself.
```

### Refined Cold-Open Hook
**Validated across:** All concrete-anchor opening papers + S1 Grandin compressed

```
+ Existing rule (cold open in first 5 seconds): keep + refine.
+   Use a SINGLE arresting quote OR a CONCRETE-ANCHOR scene.
+
+   Stereo epigraph (Grandin) — REJECT for video. Two-quote stagger is too
+   slow. Compress to one quote that frames the dialectic.
+
+   Concrete-anchor scene (Crane, Trouillot, Mamdani) — DIRECT TRANSFER.
+   Beat 1 (visual): named place, named year, named figure on screen.
+   Beat 2 (dialogue or action): a line that creates the question.
+   Beat 3 (mystery/contradiction): why what we just saw doesn't make sense.
+   Beat 4 (thesis tee-up): "Here's what the rest of the video will show."
+
+   Channel data alignment: keep cold-open under 30 seconds. Validated hook
+   types from existing data (specificity_bomb 5.4x, cold_fact 3.7x,
+   contextual_opening 2.7x — n=85 corpus) compatible with concrete-anchor
+   pattern.
```
