## STRONG SIGNALS (4+ paper validation, DIRECT TRANSFER)

### Rule 13a — Stake-Setting Setup Line Before Every Blockquote
**Validated across:** Crane, Davis, Ginzburg, Mamdani, Benton, Hobsbawm, Darnton, Grandin (8 papers)

```
+ Rule 13a (HARD): Every direct quote must be preceded by a sentence answering:
+   who is speaking, when, and what is at stake when they speak.
+   "Cobbett writes:" alone is insufficient — must be: "[Stakes context]. [Speaker] writes:"
+   Test: a reader who never finishes the quote should still understand why the
+   next paragraph matters.
```

### Rule 13b — Decode-Not-Defer (with 4 sub-patterns)
**Validated across:** Crane, Davis, Trouillot, Hobsbawm, Darnton, Grandin (6 papers, all decode mode + 4 distinct sub-patterns)

```
+ Rule 13b (HARD — pre-output gate): No blockquote may end a paragraph.
+   Every blockquote must be followed within 1-2 sentences by an authorial decode.
+   Pick one of FOUR sub-patterns based on what the quote needs:
+
+   (a) POLITICAL-INTEREST DECODE (Crane mode) — name whose interest the speaker
+       is serving. Best when the speaker has factional motives.
+       Example: "As a Federalist, Cobbett singles out Barlow to avoid directly
+       criticizing Adams."
+
+   (b) WORD-ZOOM DECODE (Hobsbawm mode) — isolate one word from the quote and
+       unpack what its presence reveals. Best when one word is doing
+       disproportionate work.
+       Example: "(The word 'improvement' introduces the characteristic note
+       of nineteenth-century progress.)"
+
+   (c) QUESTIONING RE-ENTRY (Darnton mode) — name the interpretive PROBLEM
+       before resolving it. Best when the quote is genuinely puzzling and
+       you're setting up a standard reading to demolish.
+       Example: "What is the moral of this story? ...How can one begin
+       to interpret such a text?"
+
+   (d) NAMED-EXAMPLE DECODE (Grandin mode) — "Here, then, is a remarkably
+       clear example of [thesis-relevant pattern]." Best when the source
+       illustrates a principle the article is establishing.
+
+   The decode is in the author's voice, not a neutral paraphrase.
+   Quality Gate: every blockquote in a draft must be followed by a decode.
```

### Rule 11b — Concede-and-Pivot (Steel-Man Before Pivot)
**Validated across:** Crane, Wolfe, Snyder, Mamdani, Davis (5 papers — turn-level), all 4 turn-pattern papers (S15)

```
+ Rule 11b (HARD): When the article addresses an opposing reading, give that
+   reading its strongest factual case BEFORE complicating it.
+   Two-beat structure:
+     Beat 1: "Yes, [factual claim of opposing position] is true / well-attested."
+     Beat 2: "But [the deeper thing the surface fact misses]."
+   Connectors used in corpus: "While it is clearly the case... this does not
+   mean...", "is in fact only...", "Although that history substantiates...",
+   "If we concentrate on X — generally taken to be — we fail to notice..."
+   Anti-pattern: "Some claim X, but actually..." — strawman move, kills credibility.
+   Test: a reader on the OPPOSING side should recognize their position fairly
+   stated in Beat 1.
+
+ Rule 11b extension (S10): The opening-sentence concede-and-pivot SCALES to
+   article architecture. If the hook says "you've been told X, but actually Y,"
+   the macro structure must be: dismantle X, rebuild Y. Unity of rhetoric and
+   architecture. When articles feel jumpy, check: does the body do what the
+   hook promised?
```

### Rule 8a — First-Person Triple-Use Discipline
**Validated across:** Crane, Wolfe, Cronon, Trouillot, Mamdani (5 papers; Benton is the documented n=1 exception — see "Voice flexibility note" below)

```
+ Rule 8a (STRUCTURAL): Every "I" in the article should be working in one of
+   three modes:
+     Mode A — SIGNPOSTING ("I'll show...", "I argue...") — mark structural
+              moves and lay out the route.
+     Mode B — NARRATIVE ANCHOR — opening anecdotes, research moments, scenes
+              where the author is physically present. Use SPARINGLY (1-2 per
+              article, in opening or pivot).
+     Mode C — VERDICT MARKER ("I think the deeper move here is...", "I'd
+              argue that...") — flag the strongest argumentative beats.
+   Anti-pattern: filler "I" where the sentence works without it ("I think this
+   happened in 1797" → just say "this happened in 1797").
+   Reserve the weight of "I" for argumentative work.
```

**Voice flexibility note (S2):** Benton uses "I" only in footnotes. Her invisible-author mode is a documented fallback. If the I-form isn't working for a given article, argument-led prose without authorial visibility is a valid alternative — don't force first-person where it's not working. Article-writer's first-person mandate is a deliberate identity choice, not a "good scholarly prose requires it" universal.

### Rule 22 — Recurring Anchor Discipline (NEW)
**Validated across:** Trouillot, Snyder, Crane, Wolfe, Cronon (5 papers, S14)

```
+ Rule 22 (HARD): Every article must have ONE named recurring anchor that
+   appears in opening + body + closing using the SAME WORDING.
+   Three valid types:
+     (a) COINED-TERM (Trouillot "unthinkable", Wolfe "logic of elimination")
+         — author seizes/coins a term that becomes the analytical anchor.
+     (b) PROPER-NOUN-AS-SYMBOL (Snyder "Auschwitz") — named real thing that
+         stands for a category of received misunderstanding.
+     (c) SPECIFIC-EVIDENCE (Crane "Article 11") — actual document/event as
+         spine. Discipline = use exact name every time, never paraphrase.
+   Pre-output check: identify the article's recurring anchor. If absent, add
+   one or accept that the article will feel jumpier than necessary.
+   Pairs with Rule 11b extension: anchor and macro structure should do the
+   same work. Snyder's "Auschwitz" recurs because the structure is
+   dismantle-Auschwitz / rebuild-bloodlands. Unified.
```

### Rule 23 — Turn Discipline (NEW)
**Validated across:** Crane, Trouillot, Davis, Wolfe (4 papers, S15)

```
+ Rule 23 (STRUCTURAL): The opening section must end with a visible turn —
+   the pivot from setup-question to thesis-defense. Pick ONE landing technique:
+     (a) LENS-SHIFTING ROADMAP — "It is through this lens, rather than..."
+         + trajectory map. Best for myth-busting that needs a route.
+     (b) PARADOX-FRAMING QUESTIONS — 2-3 escalating questions. Best for
+         high-level conceptual challenges.
+     (c) HISTORIOGRAPHIC "BUT" PIVOT — concede prior scholarship, ask the
+         question that opens new space. Best when challenging a specific position.
+     (d) "I CONTEND" THESIS DECLARATION — naked commitment after concession.
+         Best when the claim is sharp enough to land alone.
+   All four share: concession FIRST, claim SECOND.
+   Anti-pattern: drift from setup into body without a visible turn (article
+   feels like a list of points instead of an argument).
```

## MEDIUM SIGNALS (2-3 paper validation)

### Rule 9 — Mandatory Subheadings (NEW HARD; format-driven)
**Validated as channel rule:** academic norm = NO subheadings (Davis, Grandin, Wolfe = 3 of 4 sampled). Crane is the exception, AND his pattern is the only Substack-fit one (S9).

```
+ Rule 9 (HARD — format requirement): Article-writer MUST use subheadings.
+   Substack readers are mobile-first — long-form prose without subheadings is
+   unreadable on a phone. Academic no-subheading norm doesn't transfer.
+
+   Use Crane's pattern: ALTERNATE between thematic phrases and primary-
+   source-quote fragments.
+     Thematic example: "The Secular Opposition" / "Secular Afterlives"
+     Quote-fragment example: "Trampling upon the Cross" /
+         "Not Formally unlike the Mohammedans"
+   Each rhetorical-quote subheading is a hook — reader sees it and wants
+   to know what the quote means; the section unpacks.
+   Anti-pattern: flat descriptive labels ("The Barbary Crises") — they don't
+   earn the click-down.
+   Frequency: subheading every 300-500 words (Substack mobile reading rhythm).
```

### Rule 24 — Section Transition Mechanism (NEW STRUCTURAL)
**Validated across:** Cronon, Trouillot, Wolfe (3 papers, S13)

```
+ Rule 24 (STRUCTURAL): Every section transition must use one of three
+   handoff mechanisms — never default to "Now let's turn to..." or
+   section-header-only breaks.
+     (a) RAISED-QUESTION-THEN-ANSWERED (Cronon): P-N ends with a question,
+         P-N+1 opens with the answer. Open-loop / close-loop retention move.
+     (b) ECHO WORD (Trouillot): P-N ends on key term, P-N+1 picks up the
+         same word. Word-level continuity = audio-visual continuity.
+     (c) THEMATIC INTERROGATION (Wolfe): P-N ends with primary-source quote,
+         P-N+1 opens with a question pulled from the source's metaphor.
+         Forces the reader to sit with the source's image before the
+         analytical move.
+   The handoff IS the engagement. Section breaks without a mechanism feel
+   like list items.
```

### Refined Closing Type 4 — FULL-CIRCLE BRACKET vs. THREAD-AND-REFRAME
**Validated across:** Crane (BRACKET), Grandin (THREAD-AND-REFRAME) — S8

```
+ Closing Type 4 splits into two sub-types:
+   4a. FULL-CIRCLE BRACKET (Crane) — anchor opens + closes; body goes
+       elsewhere. Anchor and body don't share spine. Use when the article
+       covers multiple actors/eras and the anchor is just framing.
+   4b. THREAD-AND-REFRAME (Grandin) — anchor is opening + spine + closing.
+       Closing re-reads what the spine MEANT. Three uses of the same
+       source for the price of one.
+   Use 4b when one source can carry the whole article (single treaty article,
+   one ICJ paragraph, one founding speech). Stronger than 4a.
```

### Same-Evidence-Multiple-Readings Family (NEW Tier 2)
**Validated across:** Crane (Variant A+C), Cronon (Variant B), Trouillot (Variant C) — S3 — upgraded from Tier 3 (n=1) to Tier 2

```
+ Add to THESIS-DISCIPLINE.md Tier 2 — replaces single-source SAME-TEXT-DIFFERENT-EYES:
+   Pattern Family: SAME-EVIDENCE-MULTIPLE-READINGS (3 variants)
+     Variant A — DIACHRONIC RECEPTION: one document/event, era-by-era reading.
+                 Sequential structure. (Channel example: treaty article being
+                 interpreted across 200 years.)
+     Variant B — SYNCHRONIC INTERPRETIVE CONTEST: same evidence, contemporary
+                 historians, opposite conclusions. (Channel example: "Two
+                 historians read the same drought, wrote opposite books.")
+     Variant C — INSTRUMENTAL APPROPRIATION: same event, every group uses
+                 it as pretext for THEIR argument. (Channel example: "The
+                 Mason-Dixon line as weaponized memory.")
+   Variants combine: Crane = A+C (treaty read across eras AND each era using
+   it for its own fight). Two patterns running simultaneously make the
+   article tighter.
```

### Concrete Anchor Opening (CONFIRMED MEDIUM)
**Validated across:** Crane, Trouillot, Mamdani (3 papers — opening); contrast with Hobsbawm/Wolfe abstract-claim openings that need more reader work.

```
+ Opening Template: CONCRETE ANCHOR (preferred for Substack — S2 in working notes)
+   Beat 1: Specific scene/moment/event — named person, named place, named year.
+   Beat 2: A line of dialogue or specific action that creates the question.
+   Beat 3: The mystery / contradiction / omission inside the moment.
+   Beat 4: The thesis (≤12 words) — within first 200 words.
+   Validated: Crane (Obama in Cairo), Trouillot (classroom), Mamdani (1993
+   South Africa).
```

## INFORMATIONAL / TOOLKIT (1 paper, kept as optional moves)

### Sentence Rhythm Toolkit (S12)
**Single-source exemplars per pattern; combine as needed:**

```
+ Toolkit: When a beat needs energy, name the rhythm:
+   - CHAIN REPETITION (Snyder): clause-end = clause-start. Inescapable causal closure.
+     Example: "we know about Auschwitz because there were survivors, and
+              there were survivors because Auschwitz was a labour camp..."
+     Use for: the inescapable-conclusion beat after evidence.
+   - ACCUMULATING PARALLELS (Trouillot): "from X to Y, from X to Y, from X to Y"
+     compressing time/scale.
+     Use for: time-compression beats where you need to traverse decades quickly.
+   - STACCATO-TO-CASCADE (Davis): short blunt anchor → long cascade mimicking action.
+     Use for: scene-rendering moments where the prose mirrors what's happening.
+   - LIST PROPULSION (Darnton): rapid action verbs + unconjoined noun-list closer.
+     Use for: showing accumulation, decline, or breadth quickly.
+   Rule: don't write "vary sentence length" — pick the rhythm that matches the
+   action.
```

### Stereo Epigraph Opening (S1) — RARE-USE TOOLKIT
**Single-source (Grandin), high specificity required**

```
+ Toolkit: STEREO EPIGRAPH (Grandin mode) — two quotes from radically different
+   registers (canonical philosopher + popular voice) bracketing the argument.
+   Required conditions:
+     (a) high-canonical pole AND recognizable popular pole are both available
+     (b) both land for UK/DE/CA/US audience (Substack readership is
+         international)
+     (c) the article body actually plays out on the dialectic the two poles
+         establish
+   If any condition fails, default to single-quote epigraph or no epigraph.
+   This is NOT a default opening; it's a precision tool when the topic
+   genuinely has high-low poles.
```

### Stacked Definitions (S4) — COMPRESSED TOOLKIT
**Single-source (Said), too dense uncompressed**

```
+ Toolkit: STACKED DEFINITIONS (Said mode, COMPRESSED) — when introducing a
+   complex concept the article will use heavily, define it in 3 layers from
+   abstract to concrete:
+     Layer 1: Academic / field-level meaning (1 sentence)
+     Layer 2: Theoretical / epistemological meaning (1 sentence)
+     Layer 3: Material / operational meaning (1 sentence)
+   Total: ≤200 words. Reader latches onto whichever layer is most accessible.
+   Said uses 2,000 words for this; the channel uses 200.
```

## REJECTS (audience-fit failures, log so we don't reconsider)

- **Theoretical-framework section before narrative** (Crane original / Said framework). Substack reader doesn't consent to a "framework" section before story starts.
- **Formal academic register** (Said, Ginzburg in voice/density). Channel uses plain words; seriousness signal is page numbers + named scholars + primary docs, not vocabulary.
- **Repurposed-quote opening** (Cronon "In the beginning was the story"). Audience may miss the reference.
- **Scholarly-mission-statement opening** (Darnton "THIS BOOK investigates..."). Works in book preface, fails in Substack.
- **Axiomatic-declaration opening** (Wolfe "Land is life..."). Sounds platitudinous to general audience without immediate concrete grounding.
- **Interdisciplinary call-to-action closing** (Hobsbawm). Book-internal move; doesn't transfer to standalone articles.
