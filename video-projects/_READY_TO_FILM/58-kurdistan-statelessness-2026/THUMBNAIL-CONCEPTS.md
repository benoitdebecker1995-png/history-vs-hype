## BUILD SPEC (shared, notebook-grounded)
- **Canvas:** 1280×720, export <2 MB PNG/JPG.
- **Palette:** charcoal/navy **#1C2022** background; warm/muted historical tones; white or **yellow #FFD23F** text; red **#FF0000** accent (coin stamp / map highlight). Muted documentary, never saturated "YouTuber" color.
- **Hierarchy:** one hero element = 50–70% visual weight; exactly **3 elements** (anchor + overlay + one accent). A 4th element = overcrowding (−23% CTR).
- **Typography:** Anton / Bebas Neue / Impact / Oswald Bold, ALL CAPS, **white + 6px dark stroke** (or yellow stroke), ≥4.5:1 contrast. Keep text ≥40–60px off edges, **out of bottom-right** (duration badge).
- **2-second comprehension test (OVERRIDES score):** shrink to 160×90 → must instantly read (A) a face, (B) a coin, (C) a shaded map, + the bold word. Any blur → scale it up.
