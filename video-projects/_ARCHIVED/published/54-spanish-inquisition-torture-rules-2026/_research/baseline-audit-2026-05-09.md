## OVERALL VERDICT

**Pass rate across all three scripts: 33 / 33 (100%).**

The v15.0 "Baseline-Before-Exception" failure mode does **not** appear in Tripoli #51, Manhattan #45, or Hijab #52. All three scripts route every "but actually" / "loophole" / "exception" beat through one of two scaffolds before the pivot lands:
- A verbatim primary-source quote ON SCREEN (Path B), or
- Explicit VO articulation of the assumed baseline immediately before negation (Path A — typically using "Calling it X implies Y. But..." / "Here's how the story goes... There's just one thing wrong..." / "Read what the verse actually says. Not X. Not Y. Z." patterns).

The shared pattern across all three: **document-led structure**. Each script anchors its core pivots to a primary text (Schagen letter, Article 11 + Arabic manuscript, Q. 24:60 + Q. 33:33) that is visible on screen at the moment of subversion. The deictic reference ("here is what the verse actually says," "but here is what Hurgronje found," "this painting is the reason you think there were beads") forces baseline-establishment because the document itself is the baseline.

## VO-MONO RECURRENCE: FORMAT-SPECIFIC OR CHANNEL-WIDE?

The Inquisition #54 rough-cut failure pattern (VO-mono "but actually" landing on a baseline never spoken aloud and never shown) is **Format C-specific, not channel-wide.** Format C ("Format C" per Hijab metadata = mechanism-led / single-exhibit-depth / forensic close-read) is structurally vulnerable because its argumentative density tempts the writer to compress baselines into VO subordinate clauses ("the rule that torture could only happen once...") rather than landing them as standalone setup beats. The Tripoli (Document-First / Correction format), Manhattan (Myth-First / Elimination format), and Hijab #52 (Mechanism-led but explicitly using primary-source visual stacking from the 2026-05-09 Edit A/B passes) scripts all sidestep the failure because their formats demand visible primary documents at every reframe.

What this means practically: v15.0 is not retroactively needed for the audited scripts, but it is a **legitimate forward-looking safeguard for Format C and any future script that compresses primary-evidence setup into VO-only baselines.** The Inquisition #54 case shows the failure mode is real where the writer treats the rule-being-subverted as common knowledge (jurists' "torture only once" rule, Spanish Inquisition "silence = innocence" trope, CIA cold/hot-blood frame) rather than as something the audience needs taught. The fix Hijab #52 demonstrates retroactively — stacking primary documents ON SCREEN before any "actually" pivot — is exactly what v15.0 codifies. **Recommend: lock v15.0 as a Tier 1 mandate for Format C scripts, Tier 2 (default-on, can be relaxed) for document-first/myth-first formats where the baseline is structurally exposed by format.**
