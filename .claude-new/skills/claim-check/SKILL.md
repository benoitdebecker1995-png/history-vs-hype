# Claim check

The channel's whole proposition is that its claims survive inspection. A wrong number in a video about how claims get distorted is not an ordinary error; it is the channel refuting itself. This skill is how a script gets from "written" to "safe to say out loud".

It is also the skill most likely to waste a month if run badly. Research that will not close has already cost Benoit one. Verification strength scales with what a claim is carrying — it does not apply uniformly.

## First, triage the whole script

Read the complete current script before checking anything. Claims interact: a hedge in act three can rescue an overstatement in act one, and a claim that looks safe alone may be load-bearing for the video's actual thesis.

Escalate a sentence when it contains any of these:

- an exact number, date, or quantity
- a direct quotation
- a legal assertion (what a treaty said, what a court found, what a law required)
- a named attribution — X ordered, X wrote, X knew
- a claim about what a source contains
- an absolute: never, always, the first, the only, all
- a translation
- a causal claim, especially a monocausal one

Then sort what you escalated into three tiers, because they get different treatment:

**Hinge claims.** If this is wrong, the video is wrong. These get the full treatment: open the actual cited source at the actual page, confirm the wording, and record the locator. An unresolved citation stays unresolved and gets reported as unresolved — never quietly upgraded to "probably fine".

**Interpretive support.** Evidence offered for a reading. The job here is not only whether it is true but whether it supports what the script says it supports. Say explicitly what it establishes and what it does not.

**Routine background.** Uncontested context. Narrate it cleanly. Do not stage a verification performance for the year the war started; theatrical over-proof on settled facts is its own kind of dishonesty, and it burns the time the hinge claims need.

## Narration and exhibits are separate questions

A sentence being defensible does not make a document showable. These fail independently and both have to pass.

For any exhibit going on screen, confirm all five:

1. The object displayed is genuinely the source being claimed — not a reproduction, retyping, or later edition presented as the original.
2. The page actually contains the text being quoted.
3. The original language is preserved on screen, not replaced by translation alone.
4. The translation is labelled as a translation and has been checked.
5. Provenance uncertainty is visible rather than cropped out.

Surrounding ordinary text helps rather than hurts — it is part of what establishes that the object is a real document. And a primary source is not automatically the strongest visual: sometimes a map, a photograph, or a piece of testimony carries the claim better. Use the visual that materially strengthens the argument.

## Investigating a translation

Consequential translation differences deserve real work, because they are where this channel's foreign-language advantage lives and where its worst exposure sits. Compare against the original, note which rendering the script depends on, and say whether the argument survives the alternative reading. Where the difference is load-bearing and you are not confident, say that independent human judgement is warranted rather than adjudicating it yourself.

## Set the stopping condition first

Before starting, say what would end the check. Something like: every hinge claim has an opened source and page, every exhibit passes the five tests, and the strongest counterargument in the literature has been stated. Then stop there.

A source you cannot reach delays publication only if there is a concrete reason it could change a hinge claim, resolve a contradiction, or materially reframe the debate. "It might be relevant" is not that reason. If a gap remains, name it as a gap in the output — an honest recorded uncertainty is a finished check, not an unfinished one.

## Output format

A ledger, ordered by risk, not an essay. One row per escalated claim:

| Claim (as written) | Tier | Verdict | Evidence | What it does not establish |
|---|---|---|---|---|

Verdicts: **holds** · **holds narrower** (with the narrower version written out, ready to paste) · **unsupported** · **unresolved** (with what would resolve it).

Then, in a few lines: the strongest inconvenient fact the script currently concedes or avoids, and anything that has to change before filming. Corrections replace the claim in the script rather than accumulating in a separate log — go and fix the line.

If nothing escalates to unsupported or unresolved, say the script is clear and stop. Do not manufacture findings to justify the pass.
