# Channel data boundary

The active channel state is `../CHANNEL.md`. Current requests should reach supporting data through the
front-room evidence packets, which preserve source, grain, and as-of date.

Most top-level files in this folder are historical analyses, generated feeds, experiment records, or
migration evidence. Their presence does not make them current instruction. In particular, old channel
laws, command references, fixed thresholds, and composite opportunity/title/thumbnail/retention
scores must not be used as verdicts.

Active creator authority lives in `creator-model/OPERATING-MODEL.md`. Raw creator speech in
`creator-model/VOICE-EVIDENCE.md` is query-only voice evidence, not factual evidence. Current metrics
remain in their owned databases and must be reported with their dates.

Do not rewrite or delete the old laboratory in bulk. Promote a finding into `CHANNEL.md` only when it
is current, attributable, decision-relevant, and does not overstate what the evidence can establish.
