## Rules

1. **1 test per week.** Don't slow down. The more darts you throw, the faster you find a winner.
2. **Each test = different topic/audience.** Don't cluster similar topics back-to-back. Maximize diversity.
3. **Never publish Friday** (54 avg views). Monday-Thursday only.
4. **Every test passes `/greenlight`** — title score + thumbnail concept + demand check.
5. **Go-viral override:** 20K+ views in first week → drop everything, start deep dive immediately.
6. **Packaging failures ≠ topic failures.** If a test gets decent impressions but low CTR → swap title/thumbnail before abandoning topic.
7. **Sapodilla is not a test** — it's riding proven Belize demand (23K views). Treat it as a sequel, not an experiment.
