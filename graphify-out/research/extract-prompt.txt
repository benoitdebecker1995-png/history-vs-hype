## Hard rules

1. **Verbatim quotes only.** Copy from the source files exactly. No paraphrasing, no grammar fixes, no ellipsis insertion unless the source had `...`.
2. **One video per citation.** A citation's `video` field is a single slug — the one whose research file contains the quote. If the same quote literally appears in two files' verified research, emit two separate citation records.
3. **Slug attribution discipline.** Every `videos: [...]` list contains ONLY slugs whose research file actually mentions the entity/scholar/quote. Do not infer presence from general knowledge. If in doubt, omit the slug.
4. **No fabrication.** If a scholar's main_work is not stated in the corpus, omit the `main_work` field. Don't guess Penguin editions or page numbers.
5. **Edges must point to declared ids.** `source_id` and `target_id` must each match an `id` in the `entities` or `scholars` arrays you emitted.
6. **Bridges are the highest-value section. Use them generously.** Acceptable bridges include:
   - **Shared primary source** — two videos both quote the same treaty, decree, letter, manuscript
   - **Shared scholar** — same scholar cited as authoritative in 2+ videos (even if for different facts)
   - **Shared mechanism** — same legal/colonial/ideological mechanism (e.g., *uti possidetis*, *Conflict Thesis*, *Doctrine of Discovery*, *terra nullius*)
   - **Shared period/region** — 2+ videos covering events within the same century in the same imperial/colonial frame
   - **Shared methodological move** — 2+ videos using the same primary-source-on-screen rebuttal pattern against a specific scholarly consensus

   A bridge is NOT "both videos mention the British" — too broad. But it IS "both videos use a 16th-century papal bull to refute a modern political claim" — that's a load-bearing methodological bridge.

7. **Output one JSON object only.** Do not duplicate. Do not append a second copy. Stop after the closing `}`.
